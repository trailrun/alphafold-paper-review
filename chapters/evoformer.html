Chapter 04

Evoformer

AlphaFold2의 몸통(trunk)은 48개의 Evoformer 블록입니다. 이 블록은 단백질 구조 예측을 “3차원 공간의 그래프 추론 문제”로 봅니다. MSA 표현과 쌍(pair) 표현이 서로 정보를 주고받고, 쌍 표현은 삼각형 단위로 갱신되어 기하학적 일관성을 학습합니다.

  • MSA 표현과 쌍 표현의 모양과 의미를 설명할 수 있다.
  • 행/열 방향 축 어텐션(axial attention)이 왜 필요한지 계산 비용으로 이해한다.
  • 외적 평균(outer product mean)이 공진화 통계와 어떻게 연결되는지 실험한다.
  • 삼각형 곱셈 업데이트와 삼각형 어텐션의 네 가지 변형을 구분할 수 있다.

관련 원문: The AlphaFold network · Evoformer · Fig. 3a–c · Supplementary Methods 1.6

4.1두 개의 표현: MSA와 쌍

Evoformer는 두 개의 텐서를 들고 다닙니다.

  • MSA 표현 \(m \in \mathbb{R}^{N_{seq}\times N_{res}\times c_m}\), \(c_m=256\): 행 = 서열, 열 = 잔기 위치. 첫 행은 질의(query) 서열이며, 나중에 Structure Module의 단일 표현(single representation)이 됩니다.
  • 쌍 표현 \(z \in \mathbb{R}^{N_{res}\times N_{res}\times c_z}\), \(c_z=128\): 잔기 쌍 (i, j)의 관계. 논문은 이것을 방향 그래프의 간선으로 해석합니다(Fig. 3b).

4.3축 어텐션: 행 따로, 열 따로

MSA 전체(Nseq·Nres개 토큰)에 일반 셀프 어텐션을 걸면 비용이 \(O((N_{seq}N_{res})^2)\)이라 불가능합니다. 그래서 축 어텐션을 씁니다: 행 방향(같은 서열 안의 잔기끼리)과 열 방향(같은 위치의 서열끼리)을 번갈아 적용합니다. 행 방향 어텐션에는 쌍 표현에서 투영한 편향 bij가 더해집니다.

$$a^h_{sij} = \operatorname{softmax}_j\!\Big(\tfrac{1}{\sqrt{c}}\,\mathbf{q}^h_{si}\cdot\mathbf{k}^h_{sj} + b^h_{ij}\Big),\qquad \mathbf{o}^h_{si} = \mathbf{g}^h_{si}\odot\sum_j a^h_{sij}\,\mathbf{v}^h_{sj}$$
\(b^h_{ij}=\mathrm{Linear}(z_{ij})\): 쌍 표현이 “i와 j는 가까우니 서로 보라”고 MSA 어텐션을 조종합니다. \(\mathbf{g}=\sigma(\mathrm{Linear}(m_{si}))\): 게이트. 모든 서열 s가 같은 편향 bij를 공유합니다.

4.4외적 평균: MSA가 쌍에게 말하는 법

MSA 표현의 정보를 쌍 표현으로 옮기는 연산입니다. 열 i와 열 j의 벡터를 서열마다 외적하고, 서열 축으로 평균을 냅니다. 이전 연구(rawMSA)와 달리 모든 블록에서 반복되어 MSA → 쌍 소통이 계속 이어집니다.

$$\mathbf{o}_{ij} = \operatorname{flatten}\Big(\frac{1}{N_{seq}}\sum_{s}\mathbf{a}_{si}\otimes\mathbf{b}_{sj}\Big),\qquad z_{ij} \mathrel{+}= \mathrm{Linear}(\mathbf{o}_{ij})$$
\(\mathbf{a}_{si},\mathbf{b}_{sj}=\mathrm{Linear}(m_{si}), \mathrm{Linear}(m_{sj})\) (차원 32). 핵심 통찰: 만약 \(\mathbf{a},\mathbf{b}\)가 아미노산의 원-핫 벡터라면, 외적 평균은 정확히 쌍 빈도 표 \(f_{ij}(a,b)\) — 3장 공진화 통계의 재료 — 가 됩니다.

4.5삼각형으로 생각하기

쌍 표현이 하나의 3D 구조로 실현 가능하려면 수많은 제약을 만족해야 합니다. 대표적인 것이 삼각 부등식 \(d_{ij}\le d_{ik}+d_{kj}\)입니다. 그래서 논문은 쌍 표현의 갱신을 세 노드 i, j, k로 이루어진 삼각형 단위로 설계했습니다(Fig. 3c). 간선 ij를 갱신할 때, 세 번째 노드 k를 거치는 다른 두 간선의 정보를 사용합니다.

$$\text{나가는 간선:}\ \tilde z_{ij} = \mathbf{g}_{ij}\odot\mathrm{Linear}\Big(\mathrm{LN}\big(\textstyle\sum_k \mathbf{a}_{ik}\odot\mathbf{b}_{jk}\big)\Big)\qquad \text{들어오는 간선:}\ \textstyle\sum_k \mathbf{a}_{ki}\odot\mathbf{b}_{kj}$$ $$\text{시작 노드 어텐션:}\ a_{ijk} = \operatorname{softmax}_k\big(\tfrac{1}{\sqrt c}\mathbf{q}_{ij}\cdot\mathbf{k}_{ik} + b_{jk}\big),\quad \mathbf{o}_{ij}=\mathbf{g}_{ij}\odot\textstyle\sum_k a_{ijk}\mathbf{v}_{ik}$$
끝 노드 어텐션은 \(\mathbf{q}_{ij}\cdot\mathbf{k}_{kj} + b_{ki}\), 값은 \(\mathbf{v}_{kj}\). 어텐션 버전의 편향 \(b\)가 바로 삼각형의 “빠진 세 번째 간선”입니다.

두 종류를 모두 쓰는 이유

Main: 삼각형 곱셈 업데이트는 원래 어텐션보다 “더 대칭적이고 저렴한 대체물”로 개발되었고, 어텐션만 또는 곱셈만 쓰는 네트워크도 높은 정확도를 낼 수 있었습니다. 그러나 두 가지를 결합하면 더 정확했습니다.

4.6의사 코드로 다시 보기

# Evoformer block (Supplementary Algorithm 6, 단순화)
def evoformer_block(m, z):           # m: (s, r, 256), z: (r, r, 128)
    m += RowAttentionWithPairBias(m, z)   # 쌍 → MSA
    m += ColumnAttention(m)
    m += Transition(m)
    z += OuterProductMean(m)              # MSA → 쌍
    z += TriangleMultiplicationOutgoing(z)
    z += TriangleMultiplicationIncoming(z)
    z += TriangleAttentionStartingNode(z)
    z += TriangleAttentionEndingNode(z)
    z += Transition(z)
    return m, z

for l in range(48):                     # 블록마다 다른 가중치
    m, z = evoformer_block[l](m, z)
single = Linear(m[0])                     # query 행 → 단일 표현 (r, 384)
Transformer와 무엇이 다른가?

일반 Transformer는 토큰의 1차원 열을 다룹니다. Evoformer는 2차원 격자 두 개를 다루고, 그중 하나(쌍)는 기하학적 제약을 반영하는 삼각형 연산으로 갱신됩니다. 또 거의 모든 어텐션에 시그모이드 게이트가 붙어 있습니다. 이런 귀납 편향이 제한된 PDB 데이터(2018년 4월까지 공개된 구조)로도 효율적으로 학습할 수 있게 합니다.

핵심 정리

  1. Evoformer는 MSA 표현(s×r×256)과 쌍 표현(r×r×128)을 함께 갱신하는 48개 블록이다.
  2. MSA에는 행/열 축 어텐션을 쓰고, 행 어텐션에 쌍 편향을 더해 쌍 → MSA 정보 흐름을 만든다.
  3. 외적 평균은 매 블록 MSA → 쌍 정보를 전달하며, 원-핫 특징이면 쌍 빈도 표와 같다.
  4. 쌍 표현은 세 노드의 삼각형 단위로 갱신된다: 곱셈(나가는/들어오는) + 어텐션(시작/끝 노드).
  5. 삼각형 연산은 삼각 부등식 같은 3D 일관성 제약을 학습하기 위한 귀납 편향이다.

확인 퀴즈

Q1. 쌍 표현에서 MSA 표현으로 정보가 흐르는 경로는?

“we project additional logits from the pair stack to bias the MSA attention. This closes the loop…”

Q2. 삼각형 어텐션(시작 노드)에서 간선 ij를 갱신할 때 편향으로 쓰이는 간선은?

시작 노드 i를 공유하는 간선 ik에 어텐션하고, 삼각형을 닫는 “빠진 간선” jk가 편향 bjk가 됩니다.

Q3. MSA 전체에 일반 셀프 어텐션 대신 축 어텐션을 쓰는 주된 이유는?

Nseq=512, Nres=384이면 전체 어텐션 원소가 약 3.9×1010개로, 축 어텐션보다 수백 배 큽니다.
