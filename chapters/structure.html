Chapter 05

Structure Module과 IPA

Evoformer가 만든 추상적 표현을 실제 3D 좌표로 바꾸는 단계입니다. 단백질을 사슬이 아니라 서로 독립적으로 떠다니는 강체들의 “잔기 기체(residue gas)”로 보고, 회전·평행이동에 불변인 Invariant Point Attention(IPA)으로 8번 반복해 다듬습니다.

  • 백본 강체 프레임 \(T_i=(R_i,\mathbf{t}_i)\)을 N, Cα, C 원자로부터 만들 수 있다.
  • IPA의 어텐션 가중치가 전역 회전·평행이동에 불변인 이유를 수식과 실험으로 확인한다.
  • “사슬을 끊는” 표현이 왜 반복 정제에 유리한지 설명할 수 있다.
  • 비틀림각으로 곁사슬 원자를 복원하는 방식을 이해한다.

관련 원문: End-to-end structure prediction · Fig. 3d–e · Methods: IPA · Supplementary 1.8

5.2잔기 기체: 사슬을 끊어라

각 잔기의 백본(N–Cα–C)은 거의 강체입니다. 그래서 잔기 i를 하나의 강체 프레임 \(T_i=(R_i\in SO(3),\ \mathbf{t}_i\in\mathbb{R}^3)\)으로 표현합니다. 회전 \(R_i\)는 백본의 방향, \(\mathbf{t}_i\)는 Cα 위치입니다. 핵심은 이 프레임들이 서로 연결되어 있지 않다는 것입니다.

End-to-end structure prediction
“the peptide bond geometry is completely unconstrained and the network is observed to frequently violate the chain constraint during the application of the structure module as breaking this constraint enables the local refinement of all parts of the chain without solving complex loop closure problems.”

사슬로 연결된 표현(예: 비틀림각으로 백본을 생성)에서는 앞쪽 각도 하나만 바꿔도 뒤쪽 전체가 크게 휘두르며 움직입니다(“레버 팔 효과”). 잔기 기체에서는 모든 잔기를 동시에, 국소적으로 고칠 수 있습니다. 펩타이드 결합 기하는 미세조정 단계의 위반 손실과 마지막 Amber 이완으로 맞춥니다.

$$\mathbf{e}_1=\frac{\mathbf{x}_{C}-\mathbf{x}_{C\alpha}}{\lVert\cdot\rVert},\quad \mathbf{u}_2=(\mathbf{x}_{N}-\mathbf{x}_{C\alpha})-\big(\mathbf{e}_1\!\cdot\!(\mathbf{x}_{N}-\mathbf{x}_{C\alpha})\big)\mathbf{e}_1,\quad \mathbf{e}_2=\frac{\mathbf{u}_2}{\lVert\mathbf{u}_2\rVert},\quad \mathbf{e}_3=\mathbf{e}_1\times\mathbf{e}_2$$
\(R_i=[\mathbf{e}_1,\mathbf{e}_2,\mathbf{e}_3]\), \(\mathbf{t}_i=\mathbf{x}_{C\alpha}\). 그람–슈미트 과정(Supplementary Algorithm 21).

5.3Invariant Point Attention (IPA)

IPA는 일반 어텐션의 쿼리·키·값에 3D 점을 추가합니다. 각 잔기는 자기 국소 프레임 안에서 쿼리 점·키 점·값 점을 만들고, 이를 전역 좌표로 옮긴 뒤 거리로 친밀도를 계산합니다. 세 가지 항이 하나의 어텐션 가중치를 공유합니다.

$$a^h_{ij}=\operatorname{softmax}_j\Big(w_L\Big[\tfrac{1}{\sqrt{c}}\,\mathbf{q}^{h\top}_i\mathbf{k}^h_j \;+\; b^h_{ij} \;-\; \frac{\gamma^h w_C}{2}\sum_{p}\big\lVert T_i\circ\vec{\mathbf{q}}^{\,hp}_i - T_j\circ\vec{\mathbf{k}}^{\,hp}_j\big\rVert^2\Big]\Big)$$
① 단일 표현의 내적(추상) ② 쌍 표현 편향 \(b_{ij}\) ③ 3D 점 거리(기하). \(\gamma^h\)는 헤드별 학습 가중치(softplus), \(w_L, w_C\)는 스케일 상수. 출력에는 쌍 표현 값 \(\sum_j a_{ij}z_{ij}\)와 값 점 \(T_i^{-1}\circ\sum_j a_{ij}\,T_j\circ\vec{\mathbf{v}}_j\)도 포함됩니다.
왜 불변인가 — 한 줄 증명

모든 프레임에 전역 변환 \(T_g=(R_g,\mathbf{t}_g)\)을 걸면 \(T_g\circ T_i\circ\vec{q}-T_g\circ T_j\circ\vec{k} = R_g\,(T_i\circ\vec{q}-T_j\circ\vec{k})\)이고, 회전은 길이를 보존하므로 거리 항이 그대로입니다. 값 점은 마지막에 \(T_i^{-1}\)로 다시 국소 프레임에 가져오므로 출력도 불변입니다. 단백질을 통째로 돌려도 네트워크의 “생각”은 같습니다.

5.4등변 백본 업데이트

IPA로 갱신된 단일 표현 \(s_i\)에서 각 잔기가 자기 국소 프레임 기준의 작은 회전·이동 \(\Delta T_i\)를 예측하고 합성합니다.

$$(b_i,c_i,d_i,\mathbf{t}'_i)=\mathrm{Linear}(s_i),\quad \Delta R_i=\mathrm{quat}\!\left(\frac{(1,b_i,c_i,d_i)}{\sqrt{1+b_i^2+c_i^2+d_i^2}}\right),\quad T_i\leftarrow T_i\circ(\Delta R_i,\mathbf{t}'_i)$$
갱신이 국소 프레임에서 정의되므로, 입력 구조를 돌리면 출력도 똑같이 돌아갑니다(등변성). 사원수의 실수부를 1로 고정해 항등 변환 근처에서 시작합니다.

5.5곁사슬: 비틀림각으로 원자 복원

Structure Module 마지막에 작은 ResNet이 잔기마다 최대 7개의 비틀림각을 \((\sin\theta,\cos\theta)\) 쌍으로 예측합니다. 각 원자 그룹은 이상적인 결합 기하(교과서 값)를 가진 강체 그룹이므로, 각도만 알면 백본 프레임에 이어 붙여 모든 중원자 좌표를 만들 수 있습니다.

비틀림각회전축움직이는 원자 그룹
ωCi−1–Ni(펩타이드 평면; 거의 180°)
φN–Cα백본 H
ψCα–C카보닐 O
χ1–χ4Cα–Cβ, Cβ–Cγ, …곁사슬 원자들 (아미노산 종류에 따라 0–4개)
정규화 트릭

각도를 직접 회귀하면 −180°와 180°가 같은 값이라는 주기성 문제가 생깁니다. 2차원 벡터 \((\sin,\cos)\)를 예측하고 단위 원으로 정규화(+ 길이 보조 손실)하면 이 문제가 사라집니다. 대칭인 곁사슬(예: Asp, Phe의 180° 대칭)은 손실에서 두 대체 정답 중 가까운 쪽을 택합니다.

# Structure module (Supplementary Algorithm 20, 단순화)
s = Linear(LayerNorm(single)); z = LayerNorm(pair)
T = [identity frame] * N_res                  # black hole init
for l in range(8):                          # 같은 가중치 공유
    s += InvariantPointAttention(s, z, T)
    s = Transition(s)
    T = T ∘ BackboneUpdate(s)                 # 국소 프레임 기준 갱신
    loss += FAPE(T, T_true) / 8               # 중간층 보조 손실
    if l < 7: T = stop_gradient(T.rotations)  # 회전 경로 기울기 차단
angles = AngleResNet(s)
atoms = place_rigid_groups(T, angles)        # 모든 중원자 좌표

핵심 정리

  1. 각 잔기는 N–Cα–C로 정의된 강체 프레임 \(T_i=(R_i,\mathbf{t}_i)\)이며, 프레임들은 서로 연결되지 않은 “잔기 기체”다.
  2. 모든 프레임은 원점·항등 회전에서 시작해 가중치를 공유하는 8개 층에서 반복 정제된다.
  3. IPA는 국소 프레임의 3D 점 거리를 어텐션에 넣어 전역 회전·이동에 불변이다.
  4. 백본 업데이트는 국소 프레임 기준이라 등변이다. 사슬 끊김은 위반 손실과 Amber 이완으로 처리한다.
  5. 곁사슬은 (sin, cos) 비틀림각 + 이상적 강체 그룹으로 복원된다.

확인 퀴즈

Q1. 잔기 기체 표현에서 펩타이드 결합 제약을 의도적으로 풀어 둔 이유는?

“breaking this constraint enables the local refinement of all parts of the chain without solving complex loop closure problems.”

Q2. IPA의 3D 점 항이 전역 회전에 불변인 근본 이유는?

국소 점을 각 프레임으로 전역 좌표화한 뒤 차이의 노름을 쓰므로, 공통 전역 변환은 상쇄됩니다.

Q3. Structure Module 8개 층의 특징으로 옳은 것은?

반복 정제 개념을 강화하기 위해 같은 층을 8번 적용하고 중간 구조에도 손실을 겁니다.
